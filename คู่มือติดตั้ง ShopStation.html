🏪 ShopStation — คู่มือติดตั้งและใช้งาน

ระบบเก็บข้อมูลร้านค้า ร้านชำ สถานบริการในพื้นที่ และบันทึกผลตรวจผลิตภัณฑ์สุขภาพ ใช้ได้ทั้ง Android และ iPhone/iPad ข้อมูลเชื่อมกันออนไลน์ผ่าน Google Sheets มีแผนที่ และนำทางด้วย Google Maps

โครงสร้างระบบ
📱 แอป (โฟลเดอร์ app) — เป็นเว็บแอปแบบติดตั้งได้ (PWA) เปิดผ่านลิงก์ครั้งเดียว แล้วกด “เพิ่มไปยังหน้าจอโฮม” จะได้ไอคอนเหมือนแอปทั่วไป ใช้ได้แม้ไม่มีสัญญาณ แล้วส่งข้อมูลขึ้นเองเมื่อกลับมาออนไลน์
☁ หลังบ้าน (backend/Code.gs) — Google Apps Script ผูกกับ Google Sheets ของหน่วยงาน เก็บข้อมูลร้านค้า (ชีต Stores) ผลการตรวจ (ชีต Inspections) และรูปภาพลง Google Drive ไม่มีค่าใช้จ่าย
ไฟล์หน้าที่
app/index.htmlตัวแอปทั้งหมด (แบบตรวจแก้ได้ที่ส่วน CHECK ด้านบนของสคริปต์)
app/manifest.json, sw.js, icon-*.pngทำให้ติดตั้งลงมือถือและทำงานออฟไลน์ได้
backend/Code.gsโค้ดหลังบ้านสำหรับวางใน Google Apps Script

ขั้นที่ 1 — สร้างหลังบ้าน (Google Sheets + Apps Script) ~10 นาที

  1. ใช้บัญชี Google ของหน่วยงาน เข้า sheets.new สร้างสเปรดชีตใหม่ ตั้งชื่อ เช่น ShopStation ข้อมูลร้านค้า
  2. เมนู ส่วนขยาย → Apps Script → ลบโค้ดเดิม แล้ววางเนื้อหาทั้งหมดจากไฟล์ backend/Code.gs → กดบันทึก 💾
  3. เลือกฟังก์ชัน setup ในแถบด้านบน → กด เรียกใช้ → อนุญาตสิทธิ์ (ถ้าขึ้น “Google ไม่ได้ยืนยันแอปนี้” ให้กด ขั้นสูง → ไปที่ ... (ไม่ปลอดภัย) เพราะเป็นสคริปต์ของเราเอง)
  4. ดู บันทึกการดำเนินการ ด้านล่าง จะมีบรรทัด API Key ...: xxxxxxxxxxxx — จดรหัสนี้ไว้
  5. กด การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ไอคอนเฟือง เลือก เว็บแอป
    • ดำเนินการในฐานะ: ฉัน
    • ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน
    → กด ทำให้ใช้งานได้ → คัดลอก URL เว็บแอป (ลงท้ายด้วย /exec)
“ทุกคน” หมายถึงแอปเรียก URL นี้ได้โดยไม่ต้องล็อกอิน Google แต่ทุกคำสั่งต้องมี API Key ที่ถูกต้อง แจก Key เฉพาะเจ้าหน้าที่ หากรหัสหลุด ให้เรียกฟังก์ชัน resetApiKey แล้วแจ้งรหัสใหม่
ถ้าแก้โค้ด Code.gs ภายหลัง: การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ → เวอร์ชัน: เวอร์ชันใหม่ (URL เดิมจะใช้ต่อได้)

ขั้นที่ 2 — นำแอปขึ้นเว็บ (ฟรี มี https) ~10 นาที

มือถือต้องเปิดแอปผ่านลิงก์ https จึงจะใช้ GPS กล้อง และติดตั้งได้ แนะนำ GitHub Pages:

  1. สมัคร/เข้าสู่ระบบ github.com → ปุ่ม New repository ตั้งชื่อ เช่น shopstation เลือก Public → Create
  2. กด uploading an existing file → ลากไฟล์ทั้งหมดใน โฟลเดอร์ app (index.html, manifest.json, sw.js, icon-*.png) ไปวาง → Commit changes
  3. ไปที่ Settings → Pages → Source: Deploy from a branch, Branch: main / (root) → Save
  4. รอ 1–2 นาที จะได้ลิงก์ https://ชื่อผู้ใช้.github.io/shopstation/ — แจกลิงก์นี้ให้ทีม

ทางเลือกอื่น: Netlify (app.netlify.com → Add new site → Deploy manually → ลากโฟลเดอร์ app) หรือ Firebase Hosting

ลิงก์แอปเปิดเผยได้ เพราะข้อมูลจริงอยู่ใน Google Sheets และเข้าถึงได้ด้วย API Key เท่านั้น

ขั้นที่ 3 — ติดตั้งบนมือถือและตั้งค่า

  1. Android: เปิดลิงก์ด้วย Chrome → เมนู ⋮ → ติดตั้งแอป (หรือ เพิ่มไปยังหน้าจอหลัก)
    iPhone/iPad: เปิดลิงก์ด้วย Safari → ปุ่มแชร์ ⬆ → เพิ่มไปยังหน้าจอโฮม
  2. เปิดแอป → แท็บ ⚙️ ตั้งค่า → ใส่ชื่อผู้ตรวจ หน่วยงาน รายชื่อหมู่บ้าน
  3. ใส่ Web App URL และ API Key จากขั้นที่ 1 → กด ทดสอบการเชื่อมต่อ → ขึ้น “เชื่อมต่อสำเร็จ ✓”
  4. กด 📍 ตั้งจุดกลางแผนที่เป็นตำแหน่งปัจจุบัน ขณะอยู่ในพื้นที่ รพ.สต.
  5. ครั้งแรกที่เปิดให้ อนุญาตตำแหน่ง (Location) และกล้อง

การใช้งาน

เมนูใช้ทำอะไร
🗺️ แผนที่หมุดร้านทุกร้าน สีตามผลตรวจล่าสุด (เขียว ผ่าน · ส้ม ต้องปรับปรุง · แดง ไม่ผ่าน · เทา ยังไม่ตรวจ) แตะหมุด → รายละเอียด / นำทางด้วย Google Maps สลับภาพดาวเทียมได้ที่มุมขวาบน
🏪 ร้านค้าค้นหา กรองตามหมู่บ้าน/ผลตรวจ/ประเภท · ＋ เพิ่มร้านค้า: ข้อมูลร้าน (หมวด 1) ภาพหน้าร้าน พิกัดจาก GPS / ปักหมุดบนแผนที่ / วางพิกัดจาก Google Maps
📝 ตรวจประเมินแบบตรวจหมวด 2 (ยา อาหาร + Test Kit เครื่องสำอาง วัตถุอันตราย) หมวด 3 (สุขวิทยา) หมวด 4 (แหล่งสินค้า อบรม คบส. ผลรอบก่อน — แอปดึงผลครั้งก่อนมาแสดงให้อัตโนมัติ) · ปุ่ม “ผ่านทั้งหมด” / “ไม่มีจำหน่าย” ช่วยให้ตรวจเร็ว · สร้างข้อเสนอแนะอัตโนมัติ · ถ่ายรูปหลักฐาน · นัดตรวจติดตาม
🖨 ผลการตรวจแบบบันทึกพร้อมช่องลงชื่อ ผู้ประกอบการ/เจ้าหน้าที่ — กดพิมพ์หรือบันทึกเป็น PDF ส่งให้ร้านได้
📊 ภาพรวมสรุปจำนวนร้านตามผลตรวจ รายหมู่บ้าน ข้อที่พบปัญหาบ่อย ร้านที่ถึงนัดติดตาม · ส่งออก CSV เปิดด้วย Excel
เกณฑ์ผลประเมิน (คิดจากข้อที่ตอบ ผ่าน/ไม่ผ่าน ไม่นับ “ไม่มี”)
≥ 80% = ผ่าน · 60–79% = ต้องปรับปรุง · < 60% = ไม่ผ่าน
พบ ข้อสำคัญ ข้อใดข้อหนึ่ง (ยาชุด ยาซองใส ยาปฏิชีวนะ ยาแก้แพ้ฤทธิ์แรง ยาปนสเตียรอยด์ สินค้าหมดอายุ เครื่องสำอางอันตราย หรือ Test Kit พบสาร) = ไม่ผ่าน ทันที
แก้ตัวเลขเกณฑ์ได้ที่ PASS_PCT, FAIR_PCT ใน index.html

การทำงานออฟไลน์และการซิงก์

  • ทุกการบันทึกเก็บในเครื่องก่อนเสมอ ป้ายมุมขวาบนบอกสถานะ: ☁ ซิงก์แล้ว · ⬆ รอส่ง n · 📴 ออฟไลน์
  • เมื่อมีสัญญาณ แอปส่งข้อมูลและรูปขึ้น Google Sheets/Drive อัตโนมัติ และดึงข้อมูลจากเครื่องอื่นมาทุก 2 นาที (แตะป้ายเพื่อซิงก์ทันที)
  • รูปถูกย่อขนาดอัตโนมัติ (ประมาณ 100–200 KB/รูป) เก็บในโฟลเดอร์ ShopStation Photos ข้าง ๆ ไฟล์ Sheets
  • ถ้ายังไม่ใส่ URL เซิร์ฟเวอร์ แอปใช้แบบเครื่องเดียวได้ (ควรกด “สำรองข้อมูล” เป็นระยะ)

Google Maps API Key (ไม่บังคับ)

ค่าเริ่มต้นใช้แผนที่ OpenStreetMap + ภาพดาวเทียม Esri ฟรี ส่วนปุ่ม “นำทาง” และลิงก์พิกัดเปิดแอป Google Maps ได้เสมอ หากต้องการให้แผนที่ในแอปเป็น Google Maps: เข้า console.cloud.google.com → สร้างโปรเจกต์ → เปิด Maps JavaScript API → สร้าง API Key (ตั้งข้อจำกัดเป็น HTTP referrer ของลิงก์แอป) → ใส่ในหน้าตั้งค่า (ต้องผูกบัตรเครดิต แต่มีโควตาฟรีรายเดือน)

ต่อยอด: ทำเป็นไฟล์ติดตั้ง Play Store / App Store

เมื่อแอปออนไลน์แล้ว เข้า pwabuilder.com ใส่ลิงก์แอป → สร้างแพ็กเกจ Android (.aab/.apk) ได้ทันที ส่วน iOS ต้องใช้ Mac และบัญชี Apple Developer (99 USD/ปี) — สำหรับใช้งานภายในหน่วยงาน การติดตั้งผ่าน “เพิ่มไปยังหน้าจอโฮม” เพียงพอและอัปเดตได้ทันทีโดยไม่ต้องผ่านสโตร์

ข้อควรระวังด้านข้อมูล

  • ข้อมูลเจ้าของร้าน/เบอร์โทรเป็นข้อมูลส่วนบุคคล — แชร์ Google Sheets เฉพาะผู้เกี่ยวข้อง
  • รูปใน Drive ตั้งเป็น “ทุกคนที่มีลิงก์ดูได้” เพื่อให้แอปแสดงรูปได้ ลิงก์สุ่มเดายาก แต่ไม่ควรถ่ายรูปบุคคลหรือเอกสารส่วนตัว
